Why Paplyn?

Own your toolchain, your data, and your collaboration stack.

  • Self-hosted by design. One Docker Compose stack on your machine or server — no dependency on a third-party cloud editor.
  • Open source (MIT). Inspect, fork, and adapt the codebase. Star the repo to follow releases and contribute back.
  • Research-ready workflow. Multi-file projects, version history, sharing with roles, Zotero/DOI integrations, and a calm paper-inspired UI for long writing sessions.
  • Free to run. GitHub Pages for this site, Docker on your hardware — no Paplyn subscription, no surprise bills.

Self-host in minutes

Clone the repository, configure secrets, and start the stack. The first registered user becomes admin.

Docker Compose quickstart

See Configuration for every environment variable, API key, and production URL. 

git clone https://github.com/amine0110/paplyn.git
cd paplyn
cp .env.example .env
# Set BETTER_AUTH_SECRET, COLLAB_SECRET, and URLs — see configuration guide

docker compose up --build
Open http://localhost:3000, create an account, and start a project. For production behind a reverse proxy, use docker compose -f docker-compose.yml -f docker-compose.prod.yml up --build -d. Full details in the README.
