---
title: Connect Zotero
description: Get your Zotero user ID and API key to search and cite from your library in Paplyn.
section: Integrations
order: 1
slug: zotero
---

You'll need a Zotero account with at least one item in your library.

1. Open [https://www.zotero.org/settings/keys](https://www.zotero.org/settings/keys) (you must be signed in to Zotero).
2. Copy the numeric **user ID** at the top of the page ("Your userID for use in API calls").
3. Click **Create new private key**. Name it `Paplyn`, allow **library access**, leave notes and write access off, then save.
4. Copy the API key — Zotero shows it only once.
5. In Paplyn, open **Settings** and paste your user ID and API key. Never put your key in chat or email.
6. In a project, choose **Zotero** from the AI assistant or menu, search your library, then **Cite** to add entries to `references.bib`.
